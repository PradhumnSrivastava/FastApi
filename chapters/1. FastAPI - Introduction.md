#  What is FastAPI?

> **Definition**
>
> FastAPI is a **modern, high-performance Python web framework** used to build **RESTful APIs** quickly and efficiently. It is designed to create production-ready APIs with minimal code while providing automatic validation, documentation, and excellent performance.

---

##  Built On

FastAPI is built on two powerful Python libraries:

### ⭐ Starlette
Responsible for web-related functionality.

- Routing
- Request Handling
- Response Handling
- Middleware
- Background Tasks
- WebSockets

---

### ⭐ Pydantic
Responsible for data-related functionality.

- Data Validation
- Type Checking
- Serialization
- Deserialization
- Parsing JSON

---

##  Simple Definition

> FastAPI is a Python framework that helps developers build **fast, secure, scalable, and production-ready REST APIs** with automatic validation and documentation.

#  Why FastAPI?

Before FastAPI, developers mostly used Flask and Django.

Both are excellent frameworks but have some limitations for API development.

### Problems with Flask

- Manual data validation
- Manual serialization
- No automatic API documentation
- Requires many external libraries
- More boilerplate code

---

### Problems with Django

- Heavy framework
- Designed mainly for full-stack web development
- Includes many unnecessary features for APIs

---

### FastAPI solves these issues by providing

- High Performance
- Automatic Validation
- Automatic Documentation
- Async Programming
- Less Code
- Better Developer Experience

---

#  Features of FastAPI

## 1️ High Performance

FastAPI is among the fastest Python web frameworks.

Reasons:

- ASGI architecture
- Async support
- Built on Starlette

Performance is comparable to

- Node.js
- Go

---

## 2️ Automatic Data Validation

FastAPI validates request data automatically using Pydantic.

Example

```python
class Student(BaseModel):
    age: int
```

Input

```json
{
    "age": "Twenty"
}
```

Output

```
Validation Error
```

No manual validation code is needed.

---

## 3️ Automatic API Documentation

FastAPI automatically generates interactive API documentation.

Swagger UI

```
http://localhost:8000/docs
```

ReDoc

```
http://localhost:8000/redoc
```

No extra configuration is required.

---

## 4️ Type Hint Support

Python Type Hints become validation rules.

Example

```python
age: int
name: str
salary: float
```

FastAPI understands the expected data types automatically.

---

## 5️ Async Programming

Supports

```python
async
await
```

Allows handling thousands of requests concurrently.

Useful for

- Database Queries
- AI Models
- LLM APIs
- External APIs
- File Uploads

---

## 6️ Easy to Learn

If you know Python, learning FastAPI is straightforward because it follows normal Python syntax.

## 9️ Dependency Injection

#  ASGI (Asynchronous Server Gateway Interface)

## What is ASGI?

ASGI is the modern communication standard between Python web applications and web servers.

It is the successor of WSGI.

---

### Request Flow

```
Browser
    │
HTTP Request
    │
    ▼
Uvicorn (ASGI Server)
    │
    ▼
FastAPI (ASGI Application)
    │
Business Logic
    │
    ▼
HTTP Response
    │
Browser
```

### Advantages

- Async Support
- High Concurrency
- WebSockets
- Background Tasks
- Better Performance

---

#  Uvicorn

## What is Uvicorn?

Uvicorn is an **ASGI Web Server** that runs FastAPI applications.

Think of it as the engine that starts and serves your FastAPI app.

### Command

```bash
uvicorn main:app --reload
```

Where

```
main
│
└── Python File

app
│
└── FastAPI Object
```

#  Starlette

Starlette provides all the web-related functionality.

Responsibilities

- Routing
- Middleware
- Request Object
- Response Object
- Background Tasks
- WebSockets
- Sessions

FastAPI is built on top of Starlette.

---

#  Pydantic

Pydantic is responsible for data validation.

Responsibilities

- Type Validation
- Data Parsing
- JSON Conversion
- Error Messages
- Serialization
- Deserialization

Example

```python
from pydantic import BaseModel

class Student(BaseModel):
    name: str
    age: int
```

Incoming JSON

```json
{
    "name": "Pradyumna",
    "age": 22
}
```

Pydantic automatically validates the data before it reaches your business logic.

#  Interview Questions

### Q1. What is FastAPI?

A modern, high-performance Python framework for building RESTful APIs using type hints, automatic validation, and OpenAPI documentation.

---

### Q2. Why is FastAPI faster than Flask?

Because FastAPI uses **ASGI**, **Starlette**, and **async programming**, allowing it to process many requests concurrently.

---

### Q3. What is ASGI?

ASGI (Asynchronous Server Gateway Interface) is the communication standard between asynchronous Python applications and web servers.

---

### Q4. What is Uvicorn?

Uvicorn is an ASGI server used to run FastAPI applications.

---

### Q5. What is Starlette?

Starlette is the lightweight ASGI framework that provides routing, middleware, request/response handling, and other web functionalities for FastAPI.

---

### Q6. What is Pydantic?

Pydantic is the data validation library used by FastAPI to validate, parse, and serialize request and response data.

---

#  Key Takeaways

- FastAPI is a modern framework for building REST APIs.
- Built on **Starlette** (web layer) and **Pydantic** (data validation).
- Uses **ASGI** for asynchronous request handling.
- **Uvicorn** is the ASGI server that runs FastAPI.
- Provides automatic validation, documentation, and high performance.
- Widely used for AI, Machine Learning, GenAI, and production backend services.
